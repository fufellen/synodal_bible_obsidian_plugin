# Obsidian Bible Embed Style

Локальный dev vault и плагин для Obsidian, который оформляет библейские главы и embed-цитаты без огромного сгенерированного CSS под каждую книгу и главу.

## Главное

Плагин заменяет старый подход из `snippets.css`, где были десятки тысяч строк селекторов вида "если ссылка ведет на такую-то главу, применить такой-то стиль".

Теперь логика такая:

1. JavaScript-плагин определяет, что открытая заметка или embed-ссылка относится к Библии: по настраиваемой папке или по frontmatter-маркеру.
2. Плагин добавляет небольшое число CSS-классов к уже отрендеренному DOM Obsidian.
3. `styles.css` применяет один общий layout для всех книг, глав и стихов.

Новые правила не генерируются под каждую главу. Колонка номера стиха динамическая: браузер сам выделяет ширину под `2:8`, `14:11` или `118:78`, а текст стиха начинается в соседней колонке.

## Как пользоваться

### Настройки распознавания Библии

Плагин можно настроить в Obsidian:

```text
Settings -> Community plugins -> Bible Embed Style
```

Там есть два поля:

```text
Bible root folders
Bible marker CSS classes
```

`Bible root folders` — список папок, где лежит Библия. Одна папка на строку. Значение по умолчанию:

```text
Церковь/Библия/Библия/
```

`Bible marker CSS classes` — CSS-классы из frontmatter, по которым файл считается библейской главой независимо от папки. Значение по умолчанию:

```text
bible-verses
```

Это значит, что если папка Библии переедет, есть два нормальных варианта:

1. Изменить путь в настройках `Bible root folders`.
2. Оставить/добавить в главах `cssclasses: bible-verses`; тогда путь не важен.

### Обычные главы Библии

Открыть любую главу, которую плагин распознает как Библию: либо она лежит в одной из настроенных папок, либо у нее есть marker class из настроек.

Например, для стандартной настройки это любая глава из папки:

```text
Церковь/Библия/Библия/
```

В режиме чтения номера стихов должны отображаться слева от текста стиха.

Пример ожидаемой структуры в Markdown:

```markdown
#### Мал
##### Глава 4
###### 4:1
Ибо вот, придёт день...
###### 4:2
А для вас...
```

Плагин ожидает, что номер стиха является заголовком шестого уровня (`###### 4:1`), а текст стиха идет следующим абзацем.

### Embed-цитаты

В обычной заметке можно вставлять библейский стих как Obsidian embed:

```markdown
![[Мал Глава 3#3 10]]
```

Или другой существующий путь/заголовок, который Obsidian может разрешить в файл Библии:

```markdown
![[Иак глава 4#4 13]]
![[Иак глава 4#4 16]]
```

Если две соседние embed-цитаты ведут в одну и ту же главу, плагин скрывает повторный заголовок главы у второй цитаты. Получается один общий блок:

```text
Иак глава 4

4:13  ...
4:16  ...
```

Если между цитатами есть обычный текст, заголовок главы показывается снова.

## Нужно ли помечать каждую главу

Нет, если главы лежат в одной из папок из настройки `Bible root folders`.

По умолчанию плагин сам считает файл библейской главой, если его путь находится внутри:

```text
Церковь/Библия/Библия/
```

Но можно сделать распознавание независимым от пути. Для этого в главах должен быть frontmatter marker class:

```yaml
cssclasses:
  - bible-verses
```

Этот marker class больше не нужен для старого CSS, но теперь может быть полезен как универсальный признак "это глава Библии". Если папка переедет, плагин всё равно распознает такие файлы.

Если папка Библии будет переименована или перенесена, менять код больше не нужно. Достаточно открыть настройки плагина и изменить:

```text
Bible root folders
```

Если хочется полностью отвязаться от пути, оставить в главах `cssclasses: bible-verses` и оставить `bible-verses` в настройке `Bible marker CSS classes`.

## Как работает плагин

### Для открытых глав

1. Плагин получает текущий `sourcePath` из Obsidian.
2. Проверяет, что файл находится внутри одной из настроенных папок или имеет один из marker classes в frontmatter.
3. После рендера страницы добавляет класс `bible-page`.
4. Находит заголовки стихов вида `h6[data-heading*=":"]`.
5. Оборачивает пару "номер стиха + текст стиха" в строку:

```text
bible-verse-row
bible-page-verse-row
```

6. Номер получает класс `bible-verse-number`, текстовый блок получает `bible-verse-text-block`.

### Для embed-ссылок

1. Плагин находит `.internal-embed` / `.markdown-embed`.
2. Читает цель ссылки из `src`, `data-src`, `href`, `data-href`, `alt`, `aria-label` или `title`.
3. Через `metadataCache.getFirstLinkpathDest(...)` просит Obsidian разрешить ссылку в реальный файл.
4. Проверяет, что файл находится внутри одной из настроенных папок или имеет один из marker classes в frontmatter.
5. Добавляет классы и `data-*` атрибуты:

```html
data-bible-title="Иак глава 4"
data-bible-book="Иак"
data-bible-chapter="4"
data-bible-verse="13"
data-bible-reference="4:13"
data-bible-path="Церковь/Библия/Библия/..."
```

6. Размечает номер и текст стиха той же grid-строкой.
7. Для соседних embed-цитат из одной главы добавляет:

```text
bible-embed-repeated-title
```

CSS скрывает повторный заголовок главы у таких соседних цитат.

## CSS-классы

Основные классы:

```text
bible-page
bible-embed
bible-embed-repeated-title
bible-verse-row
bible-verse-first-row
bible-page-verse-row
bible-verse-number-block
bible-verse-number
bible-verse-text-block
```

Важные CSS-переменные:

```css
--bible-verse-number-gap: 0.75ch;
--bible-verse-title-to-verse-gap: 0.55em;
```

`--bible-verse-number-gap` управляет расстоянием между номером стиха и текстом.

`--bible-verse-title-to-verse-gap` управляет расстоянием между заголовком главы в embed-цитате и первой строкой стиха.

## Что плагин не делает

Плагин не:

- переименовывает файлы;
- меняет markdown-ссылки;
- редактирует текст Библии;
- удаляет `cssclasses` из глав;
- генерирует CSS под каждую книгу;
- требует править каждую главу вручную.

Он меняет только DOM после рендера Obsidian.

## Как проверить в dev vault

1. Открыть как Obsidian vault:

```text
C:\workspace\obsidian-bible-embed-style-dev
```

2. Включить community plugins, если Obsidian спросит.
3. Проверить, что включен plugin `Bible Embed Style`.
4. Открыть тестовую заметку:

```text
Tests/Bible embeds.md
```

5. Проверить:

- у `![[Иак глава 4#4 13]]` показывается заголовок `Иак глава 4`;
- у следующего `![[Иак глава 4#4 16]]` заголовок не повторяется;
- между соседними стихами нет большого пустого промежутка;
- `118:78` не наезжает на текст стиха;
- номер стиха стоит на одной строке с первой строкой текста.
- `![[Bible marker detection#1 1]]` оформляется как библейская цитата, хотя файл лежит вне папки Библии и распознается только по `cssclasses: bible-verses`.

6. Открыть обычную главу Библии, например:

```text
Церковь/Библия/Библия/Новый завет/Деян/Деян Глава 14.md
```

7. Проверить в режиме чтения:

- номера `14:1`, `14:2`, `14:3` стоят слева;
- текст стиха начинается справа от номера;
- содержимое главы не пропадает.

8. Открыть marker-based тест:

```text
Tests/Bible marker detection.md
```

9. Проверить, что номера `1:1` и `1:2` тоже стоят слева, хотя файл находится вне папки `Церковь/Библия/Библия/`.

Самый быстрый откат:

1. В Obsidian выключить plugin `Bible Embed Style`.
2. Нажать `Ctrl+R`.

Полный откат к старому CSS:

1. Взять backup:


4. Нажать `Ctrl+R` или перезапустить Obsidian.

## Возможные проблемы

### Ничего не изменилось

Проверить:

- включен ли plugin `Bible Embed Style`;
- был ли сделан `Ctrl+R` после установки;
- лежит ли файл внутри настроенной папки Библии или есть ли у него `cssclasses: bible-verses`;
- открыт ли файл в режиме чтения, а не редактирования.

### Embed не оформился

Проверить:

- Obsidian может открыть ссылку руками;
- ссылка ведет в файл, который плагин распознает как Библию: по папке или по `cssclasses: bible-verses`;
- заголовок стиха существует в целевом файле;
- номер стиха оформлен как `###### 3:10`.

### После переноса папки Библии файл перестал распознаваться

Открыть настройки `Bible Embed Style` и изменить `Bible root folders`.

Если в главах есть:

```yaml
cssclasses:
  - bible-verses
```

то можно вообще не привязываться к папке: оставить `bible-verses` в настройке `Bible marker CSS classes`.

### После изменения CSS ничего не поменялось

Обновить сниппеты или нажать `Ctrl+R`. После изменения `main.js` лучше перезапускать Obsidian.

## Ограничения текущей версии

- Настройки есть, но пока простые: список папок и список marker classes.

- Плагин зависит от текущей DOM-структуры Obsidian Reading view и embeds; при крупных изменениях Obsidian может потребоваться адаптация.
