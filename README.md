# Obsidian Bible Embed Style Dev Vault

Локальное тестовое хранилище для разработки плагина `bible-embed-style`.

## Зачем

В боевом Obsidian vault сейчас есть временный CSS-подход: большой сгенерированный список селекторов под конкретные библейские главы. Он работает, но плохо поддерживается.

Этот dev vault нужен, чтобы спокойно разработать и проверить локальный плагин вне облачного хранилища.

## Где лежит

```text
C:\workspace\obsidian-bible-embed-style-dev
```

Эта папка одновременно:

- отдельный Obsidian vault;
- git-репозиторий;
- тестовая среда для плагина.

## Что внутри

```text
.obsidian/plugins/bible-embed-style/
  manifest.json
  main.js
  styles.css

Церковь/Библия/Библия/
  ...

Тесты/
  Библейские embed-цитаты.md
Tests/
  Bible embeds.md
```

Папка `Церковь/Библия/Библия` скопирована из текущего рабочего vault, чтобы структура путей совпадала с боевой.

## Что делает плагин

Плагин после рендера markdown:

1. Находит embedded-ссылки.
2. Проверяет, что ссылка ведет в `Церковь/Библия/Библия`.
3. Добавляет embed-блоку класс `bible-embed`.
4. Добавляет `data-*` атрибуты:

```html
data-bible-title="Иак глава 4"
data-bible-book="Иак"
data-bible-chapter="4"
data-bible-verse="13"
```

5. Если две соседние embed-цитаты ведут в одну и ту же главу, у второй добавляет класс:

```text
bible-embed-repeated-title
```

CSS скрывает повторный заголовок главы у таких подряд идущих цитат.

Плагин также размечает пару "номер стиха + текст стиха" как grid-строку:

```text
bible-verse-row
bible-verse-number-block
bible-verse-text-block
```

Поэтому ширина колонки номера стиха не задается вручную. Для коротких номеров вроде `2:8` и длинных вроде `118:78` используется одна схема: первая колонка занимает ширину самого номера, а текст начинается во второй колонке.

## Как проверять

1. Открыть папку как Obsidian vault:

```text
C:\workspace\obsidian-bible-embed-style-dev
```

2. Если Obsidian спросит про community plugins, разрешить их для этого тестового vault.
3. Проверить, что включен плагин `Bible Embed Style`.
4. Открыть:

```text
Тесты/Библейские embed-цитаты.md
```

Для проверки через быстрый поиск Obsidian также есть англоязычный дубль:

```text
Tests/Bible embeds.md
```

Главный кейс:

```markdown
![[Иак глава 4#4 13]]
![[Иак глава 4#4 16]]
```

Ожидаемый вид:

```text
Иак глава 4

4:13  ...
4:16  ...
```

Второй заголовок `Иак глава 4` не должен повторяться.

## Важные ограничения

Плагин не переименовывает файлы, не меняет markdown-ссылки и не редактирует содержимое Библии. Он меняет только DOM после рендера Obsidian.

Когда плагин будет стабилен, можно будет перенести его в боевой vault и удалить из `snippets.css` сгенерированную CSS-простыню для embed-цитат.
